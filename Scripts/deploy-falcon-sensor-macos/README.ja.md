# deploy-falcon-sensor-macos

[English](README.md) | 日本語

macOS に CrowdStrike Falcon センサーをインストールし、指定したバージョンに揃えるための Jamf Pro 用スクリプトです。

CrowdStrike API を使って、対象のセンサーバージョンを調べ、インストーラーをダウンロードし、チェックサムを確認したうえでインストールとライセンス適用を行います。Mac にすでに入っているセンサーの状態に応じて、新規インストール・アップグレード・ダウングレード・再インストールのいずれかを行います。

> [!WARNING]
> 本番環境で使う前に、必ず少数の Mac でテストしてください。

## スクリプトの動作

1. CrowdStrike API のアクセストークンを取得します。
2. 指定された対象（既定は `n-1`）を、`7.02.17003` のようなセンサーバージョンに変換します。
3. Mac にインストールされているセンサーと比べて、何をするかを決めます。

   | 現在の状態 | 処理 | 内容 |
   |---|---|---|
   | 未インストール | `install` | インストールし、CCID でライセンスを適用して起動 |
   | 古いバージョン | `upgrade` | 今のセンサーに上書きでインストール。ライセンスはそのまま。新しいバージョンが動くまで待機 |
   | 新しいバージョン | `downgrade` | メンテナンストークンでアンインストールしてから、インストール・ライセンス適用・起動 |
   | 同じバージョンだが停止中 | `reinstall` | ダウングレードと同じ |
   | 同じバージョンで動作中 | `none` | 何もしない。終了コード 0 で終了 |

4. インストーラーをダウンロードし、SHA-256 チェックサムを確認します。
5. 上の表の処理を行います。
6. 終了時に作業ディレクトリを削除し、アクセストークンを無効にします。

## 動作要件

- macOS と Jamf Pro（ローカルで実行する場合は root 権限）
- CrowdStrike Falcon の API クライアント（[セットアップ](#セットアップ)を参照）
- Falcon に必要な構成プロファイル（システム拡張、フルディスクアクセスなど）。このスクリプトでは作成しないので、別途配布してください。

## セットアップ

### 1. API クライアントを作る

Falcon コンソールの **Support and resources > API clients and keys** で API クライアントを作ります。権限は必要なものだけを付けてください。

| 権限 | 必要な場面 |
|---|---|
| Sensor Download: **Read** | 常に必要 |
| Sensor update policies: **Read** | 対象がポリシー ID か `n`、`n-1`、`n-2` の場合（既定値もこれに当たります） |
| Sensor update policies: **Write** | ダウングレードや再インストールが起こりうる場合。アンインストールに使うメンテナンストークンの取得に必要 |

アップグレードは今のセンサーに上書きでインストールするので、メンテナンストークンは要りません。アップグレードしかしない運用なら、Write 権限は外しておけます。

作成後に表示される **Client ID** と **Client Secret** を控えておいてください。

### 2. API のベース URL を確認する

お使いの CrowdStrike クラウドに合わせて、次のベース URL を使います。

| クラウド | ベース URL |
|---|---|
| US-1 | `https://api.crowdstrike.com`（既定値） |
| US-2 | `https://api.us-2.crowdstrike.com` |
| EU-1 | `https://api.eu-1.crowdstrike.com` |
| US-GOV-1 | `https://api.laggar.gcw.crowdstrike.com` |

### 3. Jamf Pro にスクリプトを登録する

**設定 > コンピュータ管理 > スクリプト** で `deploy-falcon-sensor-macos.sh` をアップロードし、パラメータラベルを設定します。

| パラメータ | ラベルの例 | 必須 |
|---|---|---|
| 4 | CrowdStrike API Base URL | いいえ（既定は US-1） |
| 5 | Client ID | はい |
| 6 | Client Secret | はい |
| 7 | Target sensor (policy ID / n / n-1 / n-2 / build / version) | いいえ（既定は `n-1`） |

### 4. ポリシーを作る

ポリシーを作ってスクリプトを追加し、パラメータ値を入力して、対象の Mac をスコープに設定します。

## 対象センサーの指定方法

パラメータ 7（ローカルで実行する場合は `-v`）で対象を指定します。次のいずれかの形式が使えます。

| 形式 | 例 | 意味 |
|---|---|---|
| センサー更新ポリシー ID | `0123456789abcdef0123456789abcdef`（16進数32文字） | そのポリシーに設定されたバージョン |
| `n`、`n-1`、`n-2` | `n-1` | 最新ビルド、1つ前、2つ前 |
| ビルド番号 | `17003` | そのビルド番号のバージョン |
| バージョン番号 | `7.02`、`7.02.17003` | そのバージョン。ビルド番号を省くと、一致する中で最新のビルドを使います |

ポリシー ID を使う場合は、そのポリシーに具体的なセンサーバージョンが設定されている必要があります。

> [!NOTE]
> Falcon コンソールでホストに割り当てたセンサー更新ポリシーも、センサーのバージョンを変えることがあります。このスクリプトと違うバージョンを指していると、お互いにバージョンを変え合ってしまいます。このスクリプトにそのポリシーの ID を指定するなどして、揃えてください。

## ローカルでのテスト

```sh
sudo ./deploy-falcon-sensor-macos.sh -i <client id> [-v <target>] [-u <base url>] [-n]
```

| オプション | 説明 |
|---|---|
| `-u` | API のベース URL（既定は `https://api.crowdstrike.com`） |
| `-i` | API クライアント ID |
| `-s` | API クライアントシークレット。省略すると入力を求められます |
| `-v` | 対象センサー（既定は `n-1`） |
| `-n` | ダウンロードと確認だけを行い、実行される処理を表示します。インストールはしません |
| `-h` | ヘルプを表示します |

シークレットは `-s` を使わず、入力を求められたときに打ち込んでください。`-s` で渡すと、シェルの履歴やプロセス一覧に残ります。

最初に `-n` を付けて実行し、どのバージョンが選ばれ、どの処理になるかを確認するのがおすすめです。`-n` は root 権限なしでも動きますが、`sudo` を付けないとインストール済みのバージョンを読めないことがあります。

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 成功（「すでに最新」の場合も含む） |
| 1 | 引数が正しくない |
| 2 | CrowdStrike API のエラー（認証や権限など） |
| 3 | 対象のセンサーバージョンが見つからない |
| 4 | ダウンロードまたはチェックサムの確認に失敗 |
| 5 | アンインストールまたはインストールに失敗 |
| 6 | ライセンス適用または起動に失敗 |

## セキュリティ上の注意

- **クライアントシークレットは Jamf Pro のポリシーに保存されます。** ポリシーを見られる人なら誰でも読めるので、ポリシーを閲覧・編集できる人を絞ってください。
- **Sensor update policies: Write は強い権限です。** センサーをアンインストールできるメンテナンストークンを取り出せます。このスクリプト専用の API クライアントを使い、ダウングレードや再インストールが必要な場合だけこの権限を付けてください。
- メンテナンストークンを取り出すと、Falcon の監査ログに `Jamf Pro: reinstall Falcon sensor on <コンピュータ名>` と記録されます。
- 認証情報は標準入力経由で `curl` に渡すので、プロセス一覧には表示されません。アクセストークンはスクリプトの終了時に無効にします。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| アクセストークン取得時に終了コード 2 | ベース URL、クライアント ID、クライアントシークレット |
| それ以外の場面で終了コード 2 | API クライアントの権限（[セットアップ](#セットアップ)を参照）。ログのエラーメッセージに、失敗した API が表示されます |
| 終了コード 3 | 対象の指定が正しいか。ポリシー ID の場合は、ポリシーに具体的なバージョンが設定されているか |
| 終了コード 6 | 構成プロファイル（システム拡張、フルディスクアクセス）が配布されているか。センサーの状態は `sudo /Applications/Falcon.app/Contents/Resources/falconctl stats` で確認できます |
